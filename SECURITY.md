# Security policy

The public `1.0.6` source snapshot has not been validated on Kindle hardware. There is no stable device release at this time. See [the security model](docs/security-model.md) before exposing a running instance to a network.

Report a suspected vulnerability through GitHub's private vulnerability reporting flow when it is available for this repository. If private reporting is unavailable, open a minimal issue asking for a private reporting route; do not include exploit details, credentials, logs, or personal configuration in a public issue.

This project is intended for a trusted local network. It does not provide a public hosted service or an encrypted transport layer.
